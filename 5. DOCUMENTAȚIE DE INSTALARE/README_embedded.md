# Embedded System - Pet Feeder IoT

## Hardware Requirements
- Arduino UNO R3 (or compatible ATmega328P board)
- ESP8266-01 WiFi module
- SG90 Servomotor
- DS18B20 Temperature sensor
- HC-SR04 Ultrasonic sensor
- WS2812 RGB LED
- Active buzzer
- Tactile button
- Breadboard and jumper wires
- 5V 2A power supply
